# Portfolio — Eddie Fisher

## Mettre le site en ligne avec GitHub Pages

1. Crée un nouveau dépôt sur GitHub (public), par exemple `portfolio`.
2. Mets tout le contenu de ce dossier (les fichiers `.html`, le dossier `assets/`, ce fichier) à la racine du dépôt.
3. Dans le dépôt : **Settings → Pages**.
4. Sous "Build and deployment", choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`.
5. Le site sera disponible à `https://<ton-nom-utilisateur>.github.io/portfolio/` après quelques minutes.

## Pages du site
- `index.html` — Accueil (hero, coordonnées, résumé, contact)
- `projets.html` — Projets (Concevoir & implanter / Vérifier & maintenir)
- `formation.html` — Formation et certification
- `qui-suis-je.html` — Qui suis-je (centres d'intérêt, vélo)
- `experience.html` — Expérience (bénévolat, jobs)
- `competences.html` — Compétences (savoir-faire, logiciels, outils)
